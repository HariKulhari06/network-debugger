# Security Policy

## Supported Versions

We currently support the following versions of Tracea with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Tracea seriously. If you discover a security vulnerability, please do **not** open a public issue. Instead, please report it via the following process:

1. Send an email to **hari.choudhary1905@gmail.com** (replace with your actual security contact email).
2. Include a detailed description of the vulnerability.
3. Provide steps to reproduce the issue.
4. Mention the potential impact.

We will acknowledge your report within 48 hours and provide a timeline for a fix. Please give us reasonable time to investigate and address the issue before making any information public.
